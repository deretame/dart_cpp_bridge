## 特性

<CardGrid>
  <Card title="同步调用" icon="rocket">
    直接调用 C++ 函数，零开销同步返回。
  </Card>
  <Card title="异步协程" icon="star">
    基于 stdexec::task 和 sender 的 v2 C++20 异步支持。
  </Card>
  <Card title="Stream 流" icon="list-format">
    C++ 向 Dart 推送数据流。
  </Card>
  <Card title="反向调用" icon="random">
    C++ 调用 Dart 闭包（DartFn）。
  </Card>
  <Card title="代码生成" icon="puzzle">
    自动生成 FFI 绑定和序列化代码。
  </Card>
  <Card title="跨平台" icon="laptop">
    Windows、Linux、macOS、iOS、Android 五端支持。
  </Card>
  <Card title="纯 C API" icon="document">
    不依赖 C++ 异步内部实现的 C99 兼容桥接 API。
  </Card>
  <Card title="外部运行时集成" icon="server">
    libuv、glib、自定义事件循环通过 stdexec scheduler 接入。
  </Card>
  <Card title="异步非阻塞通道" icon="link">
    mpsc / oneshot 协程通道，构建跨线程非阻塞流水线。
  </Card>
</CardGrid>
